# ⚡ CastOverlay: Platform

> **Next-Gen E-sports Desktop Launcher & In-Game HUD Overlay**

**CastOverlay: Platform** is a lightweight, ultra-fast desktop application designed for gamers, streamers, and e-sports enthusiasts. Built on top of **Tauri v2** and **Rust**, it delivers a seamless HUD overlay and smart game launcher experience with near-zero impact on system performance or in-game FPS.

---

### ✨ Key Features

* **🚀 Ultra-Lightweight Architecture:** Powered by Tauri v2 and Rust for minimum RAM usage and maximum FPS retention.
* **🔑 Seamless Steam OAuth Integration:** Isolated popup authentication with auto-close logic that securely links your account and returns you directly to the platform.
* **🎯 Smart Library & CDN Asset Import:** Automatically filters and displays games owned on your Steam account, dynamically loading official HD banners, posters, and logos straight from the Steam CDN.
* **🆔 Steam Rich Presence:** Displays custom status on your Steam profile (`Playing via CastOverlay Platform`) with live HUD metrics.
* **🎨 Dynamic HUD Themes:** Switch instantly between high-end esports visual styles including **Cyberpunk** (Cyan/Purple), **Emerald** (Green), and **Crimson** (Red).
* **💬 Integrated Discord Community Hub:** Direct connection to the official [CastOverlay Discord Server](https://discord.com/channels/1554464065500483584/) for updates, support, and community interactions.

---

### 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons
* **Backend Framework:** Tauri v2 (Rust)
* **Authentication:** Steam OpenID / OAuth
* **Data & Assets:** Steamworks API & Steam CDN

---

### 📥 Getting Started

1. Download the latest `.exe` installer from the [Releases page](../../releases).
2. Launch **CastOverlay: Platform**.
3. Authorize with your Steam account to automatically sync your library and activate custom HUD themes.
